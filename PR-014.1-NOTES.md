# PR-014.1 — Minimal Admin Framework

## Added

- `AdminPageInterface`
- `AdminMenu`
- `AdminManager`
- `DashboardPage`
- `AdminServiceProvider`
- WordPress `admin_menu` hook registration
- Unit tests for menu registration, manager invocation, dashboard rendering, and provider wiring

## Result

After WordPress loads the application, a top-level **WP Shop Builder** menu opens the initial dashboard with version and environment information.
