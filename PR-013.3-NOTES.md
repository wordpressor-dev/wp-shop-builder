# PR-013.3 — WordPress Hook Registrar

## Added

- `HookResolver` for resolving callable handlers and invokable services through the container.
- `HookRegistrar` implementing `HookRegistrarInterface`.
- `InvalidHookHandler` exception for non-callable resolved services.
- Unit tests for callbacks, invokable services, priorities, accepted arguments, actions, and filters.

## Updated

- `WordPressServiceProvider` now registers:
  - `HookAdapterInterface`
  - `HookResolver`
  - `HookRegistrarInterface`
