# PR-013.2 — Application & Plugin Lifecycle

## Added

- WordPress `Application` lifecycle facade.
- `Bootstrap::create()` and `Bootstrap::run()` entry points.
- Base `Plugin` class and `PluginManager`.
- `WordPressServiceProvider` bindings for the application, plugin manager, and native hook adapter.
- PHPUnit coverage for application, bootstrap, provider, and plugin lifecycle behavior.
