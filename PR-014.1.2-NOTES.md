# PR-014.1.2 — WordPress Admin API Adapter

## Purpose

Replace the dynamic `add_menu_page` callable in `AdminMenu` with an explicit,
testable WordPress API adapter.

## Changes

- Added `AdminApiInterface`.
- Added `WordPressAdminApi`.
- Injected the adapter into `AdminMenu`.
- Registered adapter bindings in `AdminServiceProvider`.
- Updated admin tests to mock the interface.
- Added a native adapter failure test for environments where WordPress is not loaded.

## Verification

Run:

```bash
composer dump-autoload
composer qa
```
