# PR-014.2.1 — Environment Layer

Introduces typed, testable access to PHP, server, and WordPress environment data.

## Added

- `PhpEnvironmentInterface` and `PhpEnvironment`
- `ServerEnvironmentInterface` and `ServerEnvironment`
- `WordPressEnvironmentInterface` and `WordPressEnvironment`
- `EnvironmentServiceProvider`
- Unit and provider integration tests

## Behavior

The WordPress environment implementation returns safe fallbacks when WordPress has not been loaded. This keeps CLI tools and PHPUnit independent from a WordPress bootstrap.
