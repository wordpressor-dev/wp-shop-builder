# PR-014.1.3 — Deferred Admin Hook Registration

## Fixed

- `AdminServiceProvider::register()` now only creates and binds services.
- WordPress `admin_menu` hook registration moved to `AdminServiceProvider::boot()`.
- `WordPressServiceProvider::boot()` boots the nested admin provider.
- `Bootstrap::create()` and `Bootstrap::run()` accept an optional `HookAdapterInterface` for isolated tests.
- Bootstrap tests use `TestingHookAdapter`, so PHPUnit does not require a loaded WordPress runtime.

Production behavior remains unchanged: when no adapter is supplied, `NativeHookAdapter` is used.
